# Forkcast

Sealed AI forecasts for food ads, graded by the lunch room. Built at EAT_HACK (Really Good
Culture), 3 October 2026.

Status: in progress. Method, results and limitations land here before 17:30.

## Run

```bash
pnpm install --frozen-lockfile
pnpm dev   # fixture mode: web http://localhost:3300, api http://localhost:8787
```

Pages: `/vote` (phones), `/qr` (lunch laptop), `/dashboard` (big screen).

Team docs: `docs/designs/forkcast.md`, `docs/superpowers/specs/backend.md`,
`docs/superpowers/specs/frontend.md`.
